# Modèle TCP/IP & Outils Réseau

## Le modèle TCP/IP en couches

| Couche | Protocoles | Unité |
|---|---|---|
| Application | HTTP, HTTPS, SSH, DNS, SMTP | Message |
| Transport | TCP, UDP | Segment / Datagramme |
| Internet | IP, ICMP, ARP | Paquet |
| Accès réseau | Ethernet, Wi-Fi, PPP | Trame |

## Configuration réseau (ip command)

```bash
# Interfaces réseau
ip link show
ip addr show
ip addr show dev eth0

# Ajouter une adresse IP
ip addr add 192.168.1.100/24 dev eth0
ip addr del 192.168.1.100/24 dev eth0

# Activer/Désactiver une interface
ip link set eth0 up
ip link set eth0 down

# Table de routage
ip route show
ip route add default via 192.168.1.1
ip route add 10.0.0.0/8 via 192.168.1.254
ip route del 10.0.0.0/8

# Voisinage ARP
ip neigh show
ip neigh flush all
```

## Diagnostic réseau

```bash
# Test de connectivité
ping -c 4 -I eth0 8.8.8.8

# Tracé de route
traceroute -n 8.8.8.8
mtr --report --report-cycles=10 8.8.8.8

# Résolution DNS
dig +short google.com
dig @8.8.8.8 google.com A
dig google.com MX
nslookup google.com
host -v google.com

# Connexions actives
ss -tulnp                    # Sockets en écoute
ss -tnp state established    # Connexions établies
ss -s                        # Résumé des sockets

# Capture de trafic
tcpdump -i eth0 -n -c 100
tcpdump -i eth0 'port 443' -w /tmp/capture.pcap
tcpdump -r /tmp/capture.pcap -n
```

## Analyse avec nmap

```bash
# Découverte d'hôtes
nmap -sn 192.168.1.0/24           # Ping sweep (aucun port)
nmap -sn 192.168.1.0/24 -oG -    # Format greppable

# Scan de ports
nmap -sS 192.168.1.10             # SYN scan (furtif)
nmap -sT 192.168.1.10             # TCP connect (sans root)
nmap -sU -p 53,161,500 192.168.1.10  # UDP scan
nmap -p 1-1024 192.168.1.10       # Ports 1-1024
nmap -p- 192.168.1.10             # Tous les ports

# Détection de version et OS
nmap -sV -O 192.168.1.10
nmap -A 192.168.1.10              # Agressif (OS + versions + scripts)

# Scripts NSE
nmap --script=ssl-cert 192.168.1.10 -p 443
nmap --script=http-title 192.168.1.0/24 -p 80,443
nmap --script=vuln 192.168.1.10
```

## Netcat (nc) — le couteau suisse réseau

```bash
# Scanner des ports
nc -zv 192.168.1.10 80
nc -zv 192.168.1.10 20-25

# Écoute sur un port
nc -lvnp 4444

# Transfert de fichier
# Côté récepteur :
nc -lvp 9999 > fichier_recu.tar.gz
# Côté émetteur :
tar czf - /data/ | nc 192.168.1.5 9999

# Test HTTP basique
echo -e "GET / HTTP/1.0\r\nHost: example.com\r\n\r\n" | nc example.com 80
```
