# TP — Exploration de l'arborescence système

## Objectifs

À l'issue de ce TP, vous serez capable de :
- Naviguer efficacement dans l'arborescence Linux
- Utiliser `find`, `du`, `df` et `tree` pour analyser le système
- Identifier les types de fichiers et comprendre `/proc`

## Durée estimée : 45 minutes

---

## Exercice 1 — Cartographie du système

1. Listez tous les fichiers de configuration dans `/etc` modifiés dans les 7 derniers jours.
2. Identifiez les 10 plus gros fichiers du répertoire `/var`.
3. Affichez l'espace disque utilisé par chaque sous-répertoire de `/usr`, trié par taille décroissante.

## Exercice 2 — Analyse de /proc

1. Trouvez le PID du processus `sshd` sans utiliser `pgrep` ni `ps`.
2. Lisez les arguments de démarrage d'un processus depuis `/proc`.
3. Combien de fichiers ouverts le processus avec PID 1 (`systemd`) a-t-il ?

## Exercice 3 — Recherche avancée

1. Trouvez tous les fichiers SUID sur le système (permission spéciale permettant l'exécution avec les droits du propriétaire).
2. Cherchez tous les fichiers dont la taille est entre 100 Mo et 500 Mo.
3. Identifiez tous les liens symboliques cassés dans `/etc`.

## Exercice 4 — Points de montage

1. Listez tous les systèmes de fichiers montés avec leur type et taille.
2. Identifiez les systèmes de fichiers de type `tmpfs`.
3. Calculez le ratio utilisation/disponible de chaque partition.

---

> **Consigne** : Notez vos commandes dans un fichier `~/exploration.sh`. Le corrigé sera partagé par le formateur.
