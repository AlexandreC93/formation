# Gestion des Utilisateurs & Permissions

## Structure des comptes Linux

Linux stocke les informations des comptes dans plusieurs fichiers :

```bash
# Comptes utilisateurs
cat /etc/passwd  # login:x:UID:GID:GECOS:home:shell

# Mots de passe hashés (root seulement)
cat /etc/shadow  # login:$6$salt$hash:...

# Groupes
cat /etc/group   # groupname:x:GID:members
```

## Gestion des utilisateurs

```bash
# Créer un utilisateur avec répertoire home
useradd -m -s /bin/bash -c "Stagiaire Formation" stagiaire01

# Définir un mot de passe
passwd stagiaire01

# Modifier un utilisateur
usermod -aG sudo stagiaire01      # Ajouter au groupe sudo
usermod -s /sbin/nologin svc_app  # Interdire la connexion shell
usermod -L compte_verrouille      # Verrouiller le compte
usermod -U compte_verrouille      # Déverrouiller

# Supprimer un utilisateur et son home
userdel -r stagiaire01

# Informations sur un compte
id stagiaire01
getent passwd stagiaire01
```

## Permissions UNIX classiques

```bash
# Structure : [type][owner][group][other]
# Exemple : -rwxr-xr-- = fichier, rwx/r-x/r--

# Modifier les permissions (notation symbolique)
chmod u+x script.sh        # Ajouter exécution pour owner
chmod g-w fichier.conf     # Retirer écriture pour group
chmod o=r fichier.txt      # Lecture seule pour others
chmod a+r public.txt       # Lecture pour tous

# Notation octale
chmod 640 /etc/secret.conf  # rw-r-----
chmod 755 /usr/local/bin/   # rwxr-xr-x
chmod 600 ~/.ssh/id_rsa     # rw------- (OBLIGATOIRE pour SSH)

# Changer le propriétaire
chown root:www-data /var/www/html
chown -R admin:admin /opt/app/
```

## Permissions spéciales

```bash
# SUID (Set User ID) — exécution avec droits du propriétaire
chmod u+s /usr/local/bin/mon-outil
# Exemple natif : /usr/bin/passwd (UID=0 au runtime)

# SGID (Set Group ID) — héritage du groupe sur un répertoire
chmod g+s /var/shared/
# Tous les fichiers créés dans /var/shared héritent du groupe

# Sticky bit — seul le propriétaire peut supprimer
chmod +t /tmp/
# Protège /tmp même si tout le monde peut écrire

# Visualiser
ls -la /tmp  # drwxrwxrwt = sticky bit actif
ls -la /usr/bin/passwd  # -rwsr-xr-x = SUID actif
```

## ACL (Access Control Lists)

```bash
# Voir les ACL
getfacl /var/www/html/config.php

# Ajouter une ACL pour un utilisateur
setfacl -m u:deployer:rw /var/www/html/config.php

# Ajouter une ACL pour un groupe
setfacl -m g:devops:rx /opt/scripts/

# ACL par défaut (héritées par les nouveaux fichiers)
setfacl -d -m u:deployer:rw /var/www/html/

# Supprimer toutes les ACL
setfacl -b /var/www/html/config.php

# Mask ACL (permission maximale effective)
setfacl -m m::r /fichier  # Limite à lecture même si rw accordé
```

## Sudo et élévation de privilèges

```bash
# Éditer /etc/sudoers (TOUJOURS utiliser visudo !)
visudo

# Exemples de règles sudoers
# Autorisation complète
admin   ALL=(ALL:ALL) ALL

# Sans mot de passe pour une commande spécifique
deploy  ALL=(root) NOPASSWD: /usr/bin/systemctl restart nginx

# Groupe entier
%devops ALL=(ALL) NOPASSWD: /usr/bin/docker, /usr/bin/kubectl

# Vérifier les droits sudo d'un utilisateur
sudo -l -U deployer
```
