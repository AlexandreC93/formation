# Corrigé — Exploration de l'arborescence système

## Exercice 1 — Cartographie du système

```bash
# 1. Fichiers /etc modifiés dans les 7 derniers jours
find /etc -maxdepth 2 -type f -mtime -7 -printf '%TY-%Tm-%Td %TH:%TM  %p\n' | sort

# 2. Les 10 plus gros fichiers dans /var
find /var -type f -printf '%s %p\n' 2>/dev/null | sort -rn | head -10 | awk '{printf "%.1fMB  %s\n", $1/1048576, $2}'

# 3. Sous-répertoires de /usr triés par taille
du -sh /usr/* 2>/dev/null | sort -rh
```

## Exercice 2 — Analyse de /proc

```bash
# 1. PID de sshd via /proc sans pgrep ni ps
grep -l 'sshd' /proc/*/comm 2>/dev/null | head -5
# Ou :
ls /proc | while read pid; do
  [[ -f /proc/$pid/comm ]] && grep -q 'sshd' /proc/$pid/comm && echo $pid
done

# 2. Arguments de démarrage d'un processus (ex: PID 1234)
cat /proc/1234/cmdline | tr '\0' ' '; echo

# 3. Fichiers ouverts par PID 1 (systemd)
ls /proc/1/fd/ | wc -l
# Ou avec détails :
ls -la /proc/1/fd/ | wc -l
```

## Exercice 3 — Recherche avancée

```bash
# 1. Fichiers SUID
find / -perm -4000 -type f 2>/dev/null
# Avec détails :
find / -perm -4000 -type f -exec ls -lh {} \; 2>/dev/null

# 2. Fichiers entre 100 Mo et 500 Mo
find / -type f -size +100M -size -500M 2>/dev/null | head -20

# 3. Liens symboliques cassés dans /etc
find /etc -type l ! -exec test -e {} \; -print 2>/dev/null
```

## Exercice 4 — Points de montage

```bash
# 1. Systèmes de fichiers montés
findmnt --output TARGET,SOURCE,FSTYPE,SIZE,USED,AVAIL,USE%

# 2. Systèmes tmpfs
df -hT | grep tmpfs

# 3. Ratio utilisation/disponible
df -h | awk 'NR>1 {gsub(/%/,"",$5); if($5>0) printf "%-20s %s%% utilisé (dispo: %s)\n", $6, $5, $4}'
```
