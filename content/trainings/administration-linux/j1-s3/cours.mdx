# Processus & Supervision Système

## Gestion des processus

```bash
# Lister les processus
ps aux                      # Tous les processus, format BSD
ps -ef                      # Format POSIX complet
ps aux --sort=-%cpu | head  # Triés par CPU
ps aux --sort=-%mem | head  # Triés par mémoire

# Processus en temps réel
top
htop

# Trouver un processus
pgrep -la nginx        # PID + nom
pgrep -u www-data      # Par utilisateur

# Arbre des processus
pstree -p
```

## Signaux et gestion des jobs

```bash
# Envoyer un signal
kill -SIGTERM 1234    # Arrêt propre (15)
kill -SIGKILL 1234    # Arrêt forcé (9)
kill -SIGHUP 1234     # Rechargement config (1)
kill -SIGUSR1 1234    # Signal utilisateur

# Via pkill (par nom)
pkill -15 nginx
pkill -9 -u zombie_user  # Tuer tous les process d'un user

# Jobs en arrière-plan
commande_longue &    # Lancer en background
jobs -l              # Lister les jobs
fg %1               # Ramener au premier plan
bg %2               # Relancer en background
Ctrl+Z              # Suspendre le processus courant

# Détacher un processus du terminal
nohup commande &
disown %1
screen ou tmux      # Sessions persistantes
```

## systemd — Gestion des services

```bash
# Statut d'un service
systemctl status nginx

# Contrôle des services
systemctl start|stop|restart|reload nginx
systemctl enable nginx    # Démarrage automatique
systemctl disable nginx   # Désactiver le démarrage auto
systemctl mask nginx      # Interdire tout démarrage

# Voir tous les services
systemctl list-units --type=service --state=running
systemctl list-units --type=service --state=failed

# Journaux systemd
journalctl -u nginx              # Logs d'un service
journalctl -u nginx -f           # Suivi en temps réel
journalctl -u nginx --since "1 hour ago"
journalctl -p err -n 50          # 50 dernières erreurs
journalctl --disk-usage          # Espace utilisé
```

## Supervision des ressources

```bash
# Mémoire
free -h
vmstat 1 10              # Statistiques toutes les 1s, 10 fois
cat /proc/meminfo

# CPU
mpstat -P ALL 1 5        # Stats CPU par cœur
iostat -x 1 5            # Stats I/O disque
sar -u 1 10              # Utilisation CPU historique

# Disque et I/O
iotop                    # I/O par processus (root)
diskstat
lsblk -f                 # Partitions et FS

# Réseau
ss -tulnp               # Sockets en écoute
netstat -an | grep ESTABLISHED | wc -l
ifstat 1                 # Bande passante interface
```

## Priorité des processus (nice/renice)

```bash
# Lancer avec une priorité basse
nice -n 19 commande_lourde &

# Modifier la priorité d'un processus existant
renice -n 10 -p 1234
renice -n -5 -p 1234  # Priorité plus haute (root requis)

# Les valeurs nice vont de -20 (max priorité) à +19 (min priorité)
# Un processus normal a nice=0
```
