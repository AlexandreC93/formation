# TP — Gestion des paquets et compilation

## Objectifs

- Maîtriser APT et les dépôts
- Compiler un outil depuis les sources
- Vérifier l'intégrité des paquets installés

## Durée estimée : 45 minutes

## Exercice 1 — Audit des paquets

1. Listez les paquets installés manuellement (non auto-installés comme dépendances)
2. Identifiez les paquets dont les fichiers ont été modifiés après installation
3. Trouvez tous les paquets installés depuis un dépôt tiers (non officiel)

## Exercice 2 — Compilation de htop depuis les sources

1. Téléchargez les sources de `htop` depuis GitHub
2. Installez les dépendances de compilation
3. Compilez avec support `ncurses` uniquement (pas de sensors, pas de openvz)
4. Installez dans `/usr/local` et vérifiez que `/usr/local/bin/htop` fonctionne
5. Créez un paquet `.deb` avec `checkinstall`

## Exercice 3 — Gestion des dépôts

1. Ajoutez le dépôt officiel de Nginx mainline de façon sécurisée (clé GPG vérifiée)
2. Installez la version mainline
3. Vérifiez l'intégrité de l'installation avec `dpkg --verify`
4. Épinglez (`pin`) la version de nginx pour éviter les mises à jour automatiques

## Exercice 4 — Analyse des bibliothèques

1. Quel binaire du système utilise le plus de bibliothèques partagées ?
2. Y a-t-il des bibliothèques manquantes (broken links) dans `/usr/lib` ?
3. Comparez les bibliothèques utilisées par `/bin/bash` compilé en statique vs dynamique

> **Livrable** : Le paquet `.deb` de htop et un fichier `audit-paquets.txt` récapitulant vos trouvailles.
